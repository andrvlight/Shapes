# Shapes (Java GUI Application)

## Overview
A Java-based graphical application designed to demonstrate Object-Oriented Programming (OOP) principles through geometric shape management and visualization. The project features a functional GUI built with **Java Swing**.

## Technical Features
* **OOP Hierarchy:** Utilized inheritance and polymorphism to create a structured system of shapes (Circle, Square, Triangle, etc.).
* **GUI Development:** Built an interactive interface using **Java Swing** and **AWT** for custom rendering.
* **Dynamic Calculations:** Implemented logic for real-time calculation of area and perimeter for various geometric entities.
* **Modular Design:** Focused on code reusability and clear separation between data logic and UI components.

## Technologies Used
* **Language:** Java
* **Libraries:** Java Swing, Abstract Window Toolkit (AWT)
* **Concepts:** Inheritance, Encapsulation, GUI Event Handling.
